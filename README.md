# Chess-Game
# Professional Chess Game ♔♚

A fully interactive web-based Chess game built using HTML, CSS, and Vanilla JavaScript. This project implements core chess mechanics, professional game controls, move validation, and a clean, responsive user interface without relying on external libraries or frameworks.

## Features

♟️ **Complete Chess Gameplay**

* Standard 8×8 chessboard
* All official chess pieces and movement rules
* Turn-based gameplay for White and Black players
* Move validation for every piece

👑 **Advanced Chess Rules**

* Check detection
* Checkmate detection
* Stalemate detection
* Castling (King-side and Queen-side)
* En Passant captures
* Pawn Promotion with piece selection
* Legal move filtering to prevent self-check

📋 **Game Management**

* Move history tracking using algebraic-style notation
* Undo move functionality
* Draw offer system
* Resignation option
* New game reset

🎯 **Visual Enhancements**

* Highlight selected pieces
* Display valid moves and capture opportunities
* King-in-check visual alerts
* Captured pieces tracker
* Professional game-over modals
* Smooth animations and responsive design

📱 **Responsive Design**

* Optimized for desktop, tablet, and mobile devices
* Adaptive board sizing
* Clean and modern user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* Event Handling
* Object-Oriented Game Logic

## Technical Highlights

This project demonstrates complex game development concepts including chess rule implementation, move validation algorithms, board state management, check/checkmate analysis, special move handling, game history tracking, and responsive UI development.

The application maintains complete game state, validates legal moves in real time, prevents illegal king exposure, and supports advanced chess mechanics such as castling, en passant, and pawn promotion.

A great project for learning JavaScript game development, algorithmic problem-solving, state management, and front-end application architecture.
